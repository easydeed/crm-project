# OR-013 — compose and send

Branch: feat/compose-and-send

Compose builds one recipient row per eligible contact. Send delivers through
Postmark only after assertSendAllowed. Tests use FakeMailer. SEND_ENABLED
stays false in committed code and CI.

The jobs unique index stays on run_after. A comment on that index says retries
must update the same row. A new row for a retry would miss the index and could
send twice.
